Installation

Live · v3 Working copy has unpublished edits

Beyond Notes ships as a single container. You need Docker and a volume for your data — that's the whole footprint.

Requirements

  • Docker 24+ with Compose
  • 1 GB RAM (2 GB recommended with search indexing)
  • A domain, if you plan to publish spaces to the web

Quick start

curl -O https://beyond.example/docker-compose.yml docker compose up -d open http://localhost:3800
💡 The first account created becomes the owner. Publishing stays disabled until you set a domain in Settings → Sites.

Set up your first space

Create a space, pick its mode — notes, journal, stream — and start writing. Publishing is off by default for every new space.
